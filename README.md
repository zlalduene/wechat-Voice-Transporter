# 语音搬运工 · WeChat Voice Transporter

> 把手机里的任意音频，变成微信聊天里的一条**真正的语音消息** —— 带时长、能转文字、能转发，而不是一个音频文件。

微信的语音是它自己录出来的 SILK 文件，普通 App 不 root 写不进微信的数据目录。  
这个项目的做法很直接：**让微信自己录一遍**。用无障碍服务替你在聊天框的「按住 说话」上下发长按手势，同时把准备好的音频从喇叭放出来，微信的麦克风收进去，于是一条真语音就诞生了。

## 功能特性

### 找音频

- 点「选择音频文件」会**直接列出手机里的所有音频**（扫描系统媒体库 MediaStore），不用一个个文件夹翻；
- 列表支持**按文件名 / 文件夹名搜索**，支持**按时间 / 按名称排序**，可切换升序、降序；
- 每行显示时长、所在文件夹、大小、修改日期，点一下即可使用；
- 想自己翻文件夹的也保留原路：列表底部「从文件夹里选…」走系统文件管理器；
- 解析音频期间按钮会显示「正在解析，请稍候…」。

### 处理音频

- 支持 mp3 / m4a / wav / flac / ogg / amr / aac 等系统能解码的格式；
- 波形裁剪：拖动选择要发送的片段（微信上限 60 秒，这里最多 56 秒）；
- 三档预设：**清晰**（电话频带，推荐）、**保真**、**响**（更窄频带 + 更高电平）；
- 响度微调（-6 ~ +8 dB）、自动削掉首尾静音；
- 试听随时可停（同一按钮切换「试听 / 停止试听」）。

### 发送到微信

- 无障碍服务自动定位微信的「按住 说话」：优先用校准坐标，其次读控件文字，最后按几何结构推测；
- 下发长按手势的同时播放音频，并**在按下的位置画一个红点**，方便确认到底按在了哪里；
- 悬浮球点一下开始发送，**发送中再点一下立刻停止**；
- 换机型 / 微信改版后可手动校准一次坐标；
- 内置诊断：显示无障碍、控件树可读性、命中的目标与方式。

### 悬浮球

- 可随意拖动，**永远不会拖出屏幕**（会避开状态栏、导航栏、刘海）；
- 位置会记住，下次显示还在原处；转屏后自动重新贴边；
- 图标随状态切换：`▶` 可发送 · `Ⅱ` 发送中（橙色）· `■` 录音中（红色）；
- **长按弹出菜单**：发送 / 停止发送、开始 / 停止录音、重新校准、使用说明、诊断、隐藏悬浮球；
- 第一次显示时有操作提示，菜单里也有完整的「使用说明」。

### 录音

- 刷视频时听到想发的声音，长按悬浮球 →「开始录音」即可录下来；
- 顶部显示「录音中 x.x 秒」，再点一下球停止，最长 59 秒自动停止；
- 录完自动走和导入文件相同的处理流程，处理完悬浮球变绿，点一下就能发到微信；
- 录音走的是麦克风，所以**要外放**（戴耳机就录不到了）。

### 环境自检

- 满音量播一段测试音，同时用麦克风录回来，量化「外放被收进去衰减了多少 dB」并给出结论；
- 可以回放自检采集到的音频，判断外放→麦克风这条路在你这台机器上是否可行。

## 系统要求

| 项目 | 要求 |
| --- | --- |
| 系统版本 | Android 7.0（API 24）及以上 |
| 目标版本 | Android 14（targetSdk 34） |
| 必要权限 | 无障碍服务（自动长按 / 悬浮球）、麦克风（录音、自检） |
| 可选权限 | 音乐和音频（Android 13+ 的 `READ_MEDIA_AUDIO`，用于列出音频） |
| 网络 | 不需要，App 本身不联网 |

> 微信版本没有硬性限制，但不同版本的界面结构不同，第一次使用需要校准一次「按住 说话」的坐标。

## 构建与安装

需要 JDK 17 和 Android SDK 34：

```bash
git clone https://github.com/zlalduene/wechat-Voice-Transporter.git
cd wechat-Voice-Transporter
./gradlew assembleDebug
```

产物在：

```
app/build/outputs/apk/debug/app-debug.apk
```

也可以直接用 Android Studio 打开工程运行。  
Release 包：`./gradlew assembleRelease`（工程内已配置调试签名，正式发布请换成自己的签名）。

## 第一次使用

1. 打开 App，点「去开启无障碍服务（自动定位到本应用）」，在系统设置里给「语音搬运工」授权；
2. 点「选择音频文件」，从列表里选一个音频（或点底部按钮去文件夹里选）；
3. 拖动波形选片段、选处理方式，点「生成语音片段」；
4. 点「显示悬浮球」；
5. 切到微信，打开聊天并切到语音输入模式，让「按住 说话」露出来；
6. **第一次**点绿色圆球会进入校准：按提示点一下微信的「按住 说话」，记住坐标；
7. 之后每次点圆球 = 自动长按 + 播放音频 = 发出一条语音消息。

建议第一次先跑一遍「环境自检」，确认你这台手机的外放 → 麦克风衰减在可接受范围内。

## 悬浮球怎么用

| 操作 | 效果 |
| --- | --- |
| 点一下 | 发送当前语音；发送中再点一下 = 停止发送；录音中再点一下 = 停止录音 |
| 长按 | 打开菜单：发送 / 停止发送、开始 / 停止录音、重新校准、使用说明、诊断、隐藏 |
| 拖动 | 移动位置，自动记忆，不会出屏幕 |

菜单里的「重新校准按钮位置」用于换机型、微信改版、输入法布局变化后重新定位。

## 权限与隐私

| 权限 | 用途 | 是否必须 |
| --- | --- | --- |
| 无障碍服务 | 找到微信的「按住 说话」、下发长按手势、显示悬浮球 | 必须 |
| 麦克风 `RECORD_AUDIO` | 悬浮球录音、环境自检与回采 | 录音/自检需要 |
| 音乐和音频 `READ_MEDIA_AUDIO`（旧系统为 `READ_EXTERNAL_STORAGE`） | 列出手机里的音频文件 | 可选，不授权也可以走文件管理器 |

- App **不申请联网权限**，不读取、不上传、不保存任何聊天内容；
- 无障碍服务只读取当前界面的控件信息用于定位按钮；
- 所有音频处理都在本机完成。

## 常见问题

**Q：发送出去的语音没声音 / 声音很小？**  
先跑「环境自检」。如果衰减超过 -36 dB，说明手机在录音时做了很强的回声消除，软件路线基本走不通，需要耳机孔回环线；-10 dB 以内属于正常可用。

**Q：点了悬浮球没反应，或者定位失败？**  
长按悬浮球 →「重新校准按钮位置」，重新点一下微信的「按住 说话」。也可以点菜单里的「诊断状态」看命中了什么。

**Q：无障碍服务总是被系统关掉？**  
很多国产 ROM 在 App 被「强行停止」后会清掉无障碍授权。建议：打开自启动、允许后台高耗电、不要从最近任务里划掉它，必要时锁定后台。

**Q：悬浮球菜单里录音没有声音？**  
录音走麦克风，刷视频时必须外放；戴耳机时麦克风收不到视频声音。

**Q：音频列表里没有我要的文件？**  
部分刚拷贝进手机的文件还没被系统媒体库索引，点列表底部的「从文件夹里选…」用系统文件管理器即可。

**Q：为什么不直接把音频写进微信？**  
微信语音是它自己的 SILK 格式，存在私有数据目录，不 root 无法写入。所以这里选择「让微信自己录」，音质取决于手机外放和麦克风。

## 项目结构

```
app/src/main/java/com/example/wechat_talking/
├── MainActivity.kt              # 入口：权限、文件选择、无障碍跳转
├── AppHub.kt                    # 全局状态：选中的音频、参数、片段、试听
├── SelfTest.kt                  # 外放 → 麦克风 衰减自检
├── audio/
│   ├── AudioDecoder.kt          # MediaExtractor + MediaCodec 解码
│   ├── AudioLibrary.kt          # MediaStore 音频扫描
│   ├── Dsp.kt                   # 滤波、归一化、削静音等轻量 DSP
│   ├── VoicePreparer.kt         # 片段处理流水线
│   └── WavIo.kt                 # 16bit PCM WAV 读写
├── auto/
│   ├── RecordButtonService.kt   # 无障碍服务：定位「按住 说话」、悬浮球、菜单、录音
│   ├── OverlayRecorder.kt       # 悬浮球麦克风录音
│   └── AutoSettings.kt          # 校准坐标、参数、悬浮球位置
├── play/
│   ├── VoiceCastEngine.kt       # AudioTrack 播放（可回采）
│   ├── CastState.kt             # 播放状态
├── ui/
│   ├── HomeScreen.kt            # 主界面
│   ├── AudioPickerScreen.kt     # 音频列表（搜索 / 排序）
│   └── WaveformView.kt          # 波形与裁剪
└── ui/theme/                    # Compose 主题
```

## 技术栈

- Kotlin + Jetpack Compose（Material 3）
- 无障碍服务（`AccessibilityService` + `dispatchGesture`）实现自动长按与悬浮窗
- `MediaExtractor` / `MediaCodec` 解码，`AudioTrack` 播放
- 自研轻量 DSP：电话频带滤波、RMS 归一化、软限幅、静音裁剪、线性重采样
